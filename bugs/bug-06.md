# BUG-06: Отсутствует подтверждение успешной регистрации

## Окружение
- Браузер: Chrome
- ОС: Windows 10

## Предусловие
Пользователь зарегистрирован

## Шаги для воспроизведения
1. Ввести email и пароль
2. Нажать "Зарегистрироваться"

## Ожидаемый результат
Появляется сообщение: "Регистрация успешна", перенаправление на главную страницу

## Фактический результат
Нет уведомления, пользователь остается на той же странице

## Серьезность
Minor

## Приоритет
Low

## Примечания
UX-проблема, пользователь не понимает результат действия
