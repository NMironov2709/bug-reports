# BUG-01: Не работает кнопка регистрации

## Окружение
- Браузер: Chrome
- ОС: Windows 10

## Предусловие
Пользователь находится на странице регистрации

## Шаги для воспроизведения
1. Ввести валидный email
2. Ввести валидный пароль
3. Нажать кнопку "Зарегистрироваться"

## Ожидаемый результат
Пользователь успешно регистрируется

## Фактический результат
Ничего не происходит, страница не реагирует

## Severity
Critical

## Priority
High
