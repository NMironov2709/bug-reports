# BUG-02: Некорректный email принимается формой регистрации

## Окружение
- Браузер: Chrome
- ОС: Windows 10

## Предусловие
Страница регистрации открыта

## Шаги для воспроизведения
1. Ввести email: "123"
2. Ввести пароль
3. Нажать "Зарегистрироваться"

## Ожидаемый результат
Появляется сообщение об ошибке: "Некорректный email"

## Фактический результат
Форма принимает данные без ошибки

## Серьезность
Major

## Приоритет
Medium

## Примечания
Валидация email не работает на фронтенде
