# BUG-03: При неверном пароле сообщение об ошибке не отображается

## Окружение
- Браузер: Chrome
- ОС: Windows 10

## Предусловие
Пользователь зарегистрирован

## Шаги для воспроизведения
1. Ввести email
2. Ввести неверный пароль
3. Нажать "Войти"

## Ожидаемый результат
Отображается сообщение об ошибке: "Неверный пароль"

## Фактический результат
Ничего не происходит

## Серьезность
Major

## Приоритет
Medium

## Примечания
Ошибка с обработкой логина на фронтенде
