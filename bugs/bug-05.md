# BUG-05: Пароль может быть меньше 8 символов

## Окружение
- Браузер: Chrome
- ОС: Windows 10

## Предусловие
Пользователь на странице регистрации

## Шаги для воспроизведения
1. Ввести валидный email
2. Ввести пароль: 123
3. Нажать "Зарегистрироваться"

## Ожидаемый результат
Сообщение об ошибке: "Пароль должен быть не менее 8 символов"

## Фактический результат
Пользователь успешно регистрируется с коротким паролем

## Серьезность
Major

## Приоритет
Medium

## Примечания
Валидация пароля отсутствует на фронтенде и/или бэкенде
