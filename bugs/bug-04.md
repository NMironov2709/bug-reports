# BUG-04: Поля формы не валидируются на пустые значения

## Окружение
- Браузер: Chrome
- ОС: Windows 10

## Предусловие
Страница регистрации или логина открыта

## Шаги для воспроизведения
1. Оставить поля пустыми
2. Нажать кнопку "Зарегистрироваться" или "Войти"

## Ожидаемый результат
Появляется сообщение об ошибке: "Поле обязательно для заполнения"

## Фактический результат
Форма отправляется, пользователь видит пустую страницу

## Серьезность
High

## Приоритет
High

## Примечания
Не реализована валидация обязательных полей
