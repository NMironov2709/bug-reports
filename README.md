# Bug Reports Project

## 📌 Описание
В данном репозитории представлены примеры баг-репортов, составленных в процессе тестирования веб-приложения (регистрация и авторизация)

## 🎯 Цель
Показать навыки:
- поиска дефектов
- оформления баг-репортов
- анализа поведения системы

## 🛠 Используемые инструменты
- Ручное тестирование
- Chrome DevTools

## 📂 Структура
Каждый файл содержит отдельный баг-репорт
